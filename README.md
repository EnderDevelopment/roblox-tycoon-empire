# Roblox Tycoon Empire

Roblox Tycoon Empire is a comprehensive Roblox script designed to create a tycoon game. It includes server and client scripts, modules for player, game, and shop management, and user interfaces for player, shop, and inventory. The project aims to provide a robust foundation for building a tycoon game with features like player data management, game state handling, shop transactions, and interactive UIs.

## Install

1. Place the server scripts in the respective paths under `ServerScriptService`.
2. Place the client scripts in the respective paths under `StarterPlayerScripts`.
3. Place the modules in the respective paths under `ReplicatedStorage`.

## Use

1. Ensure all scripts and modules are properly linked and referenced in the game hierarchy.
2. Test each script individually before combining them into the final game.
